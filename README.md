# neural-lab

A personal reference for learning about neural networks — concepts and definitions first, code experiments later.

## Docs

- [Introduction to neural networks](docs/01-introduction.md) — what a neural network is, why it matters, and a brief history from the perceptron to the Transformer.
- [Core concepts and definitions](docs/02-core-concepts.md) — precise definitions of neurons, weights, biases, layers, activation functions, and related terms.
- [How neural networks learn](docs/03-training-and-learning.md) — loss functions, gradient descent, backpropagation, and how overfitting is diagnosed and mitigated.
- [Architectures overview](docs/04-architectures-overview.md) — feedforward networks, CNNs, RNNs/LSTMs, Transformers, autoencoders, and GANs, with guidance on when each applies.
- [Glossary](docs/05-glossary.md) — a flat, alphabetical quick-reference for every term used across the docs above.

## Reading order

Read the docs in numeric order — each builds on terms defined in the previous one. The glossary is a lookup table, not something you read start to finish.

## Scope

This repository is a study reference, not a library or tutorial with runnable code. Implementation experiments, when added, will live in their own directories alongside the docs they exercise.
