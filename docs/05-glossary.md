# Glossary

A flat, alphabetical quick-reference for terms used across this repository. See the linked document for full context on each term.

- **Activation function** — a nonlinear function applied to a neuron's weighted sum; without it, stacked layers reduce to one linear transformation. [`02-core-concepts.md`](02-core-concepts.md)
- **Backpropagation** — the algorithm that computes the gradient of the loss with respect to every weight, working backward from the output layer using the chain rule. [`03-training-and-learning.md`](03-training-and-learning.md)
- **Batch** — a subset of the training data processed together in one forward/backward pass. [`03-training-and-learning.md`](03-training-and-learning.md)
- **Bias** — a learned scalar added to a neuron's weighted sum, independent of the input. [`02-core-concepts.md`](02-core-concepts.md)
- **Convolutional neural network (CNN)** — an architecture that uses shared, sliding filters to exploit spatial structure, most commonly in images. [`04-architectures-overview.md`](04-architectures-overview.md)
- **Dropout** — a regularization technique that randomly disables a fraction of neurons during training to reduce overfitting. [`03-training-and-learning.md`](03-training-and-learning.md)
- **Epoch** — one full pass over the entire training dataset. [`03-training-and-learning.md`](03-training-and-learning.md)
- **Forward pass** — the process of computing a prediction by passing input through the network layer by layer. [`02-core-concepts.md`](02-core-concepts.md)
- **Generalization** — how well a trained model performs on data it did not train on. [`03-training-and-learning.md`](03-training-and-learning.md)
- **Gradient descent** — the optimization algorithm that updates parameters in the direction that reduces loss. [`03-training-and-learning.md`](03-training-and-learning.md)
- **Hidden layer** — any layer between the input and output layers. [`02-core-concepts.md`](02-core-concepts.md)
- **Hyperparameter** — a value set by a human before training (learning rate, layer count, etc.), as opposed to a learned parameter. [`02-core-concepts.md`](02-core-concepts.md)
- **Layer** — a group of neurons that receive the same input and compute in parallel. [`02-core-concepts.md`](02-core-concepts.md)
- **Learning rate** — the step-size hyperparameter in gradient descent. [`03-training-and-learning.md`](03-training-and-learning.md)
- **Loss function** — a function measuring the discrepancy between a prediction and the true target. [`03-training-and-learning.md`](03-training-and-learning.md)
- **LSTM (Long Short-Term Memory)** — a recurrent architecture with learned gates that mitigate the vanishing-gradient problem over long sequences. [`04-architectures-overview.md`](04-architectures-overview.md)
- **Model capacity** — informally, how complex a function a network can represent, generally growing with parameter count. [`02-core-concepts.md`](02-core-concepts.md)
- **Neuron (unit)** — the basic computational element: a weighted sum of inputs plus a bias, passed through an activation function. [`02-core-concepts.md`](02-core-concepts.md)
- **Overfitting** — when a model has effectively memorized training data and performs much worse on unseen data. [`03-training-and-learning.md`](03-training-and-learning.md)
- **Parameter** — a value the training algorithm learns automatically (a weight or bias), as opposed to a hyperparameter. [`02-core-concepts.md`](02-core-concepts.md)
- **Recurrent neural network (RNN)** — an architecture that maintains a hidden state across sequence steps, suited to sequential data. [`04-architectures-overview.md`](04-architectures-overview.md)
- **Self-attention** — a mechanism where each element of a sequence attends to every other element with learned weights; the core operation of the Transformer. [`04-architectures-overview.md`](04-architectures-overview.md)
- **Tensor** — an n-dimensional array of numbers; the core data structure of neural network frameworks. [`02-core-concepts.md`](02-core-concepts.md)
- **Transformer** — an architecture built entirely on self-attention rather than recurrence; the basis for modern large language models. [`04-architectures-overview.md`](04-architectures-overview.md)
- **Underfitting** — when a model is too simple (or undertrained) to capture the pattern in the data. [`03-training-and-learning.md`](03-training-and-learning.md)
- **Weight** — a learned scalar that scales one input's contribution to a neuron's weighted sum. [`02-core-concepts.md`](02-core-concepts.md)
